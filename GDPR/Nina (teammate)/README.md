# GDPR Peer Audit – Company Research Bot

This repository contains my independent first-pass GDPR compliance assessment of **Janaina Hoffmann's Project 3 – Company Research Bot**, completed as part of the AI Consulting Bootcamp.

## Repository structure

| File | Description |
|------|-------------|
| `GDPR_Peer_Audit_Company_Research_Bot.md` | Independent GDPR peer audit covering all required phases of the lab, including personal data inventory, role mapping, lawful basis review, compliance findings and recommendation. |
| `DATA_PROCESSING_BRIEF.md` | Data Processing Brief provided by the project author and used as the basis for this independent assessment. |

## Scope

This assessment is based exclusively on the documentation provided by the project author and reflects an independent first-pass GDPR review. It is **not** a legal opinion, Data Protection Impact Assessment (DPIA), or certification of GDPR compliance.
