# GDPR Lens Lab – Project 3 Audit

This repository contains my first-pass GDPR compliance assessment for **Project 3 – VR Competitive Intelligence Copilot**, completed as part of the AI Consulting Bootcamp.

## Repository structure

| File | Description |
|------|-------------|
| `GDPR_Compliance_Assessment.md` | Complete GDPR audit covering all required phases of the lab, including personal data inventory, role mapping, lawful basis assessment, risk analysis, law stacking and compliance memo. |
| `DATA_PROCESSING_BRIEF.md` | Data Processing Brief describing the system's personal data flows, processing activities and architecture. This document serves as the factual basis for the audit. |

## Scope

This assessment is an educational first-pass GDPR review and is **not** a legal opinion, Data Protection Impact Assessment (DPIA), or certification of compliance.
